# Student Grade Management System

A simple **Student Grade Management System** developed using Python. This console-based application allows users to manage student records and calculate their academic performance.

## Features

* Add student details
* Enter marks for Python, Mathematics, and Programming
* Calculate total marks
* Calculate average marks
* Automatically assign grades
* Display all student records
* Search for a student using their roll number
* Find the highest-scoring student
* Simple menu-driven interface

## Grading System

| Average Marks | Grade |
| ------------- | ----- |
| 90 or above   | A+    |
| 80–89         | A     |
| 70–79         | B     |
| 60–69         | C     |
| 50–59         | D     |
| Below 50      | F     |

## Technologies Used

* Python
* Python Lists
* Python Dictionaries
* Functions
* Loops
* Conditional Statements
* Console Input/Output

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python SGMS.py
```

5. Select an option from the menu.

## Menu Options

```text
1. Add Student
2. Display All Students
3. Search Student
4. Find Highest Scorer
5. Exit
```

## Project Purpose

This project was created to practice Python programming concepts such as functions, lists, dictionaries, loops, conditional statements, user input, and basic student record management.
