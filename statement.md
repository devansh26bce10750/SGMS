# Project Statement - Student Grade Management System

# Problem statement

Handling marks for students by hand can become repetitive, especially when total marks, averages, and the highest scorer have to be worked out again and again. For a small class, a simple console program can make these routine steps quicker and more organised.

## Project scope

The present version focuses on in-memory student records during one program run. It accepts a roll number, student name, and marks in Python, Mathematics, and Programming. It provides basic record display, roll-number search, and highest-scorer analysis.

The project does not use a database or permanent file storage. When the program is closed, the records are lost. Features such as editing/deleting records, saving data to a file or database, login, and a graphical interface are outside the present scope and are listed as future enhancements.

## users

The main target users are students, teachers, or anyone who needs a small classroom-style console utility for entering and viewing academic marks.

# features

1. Add student details and marks.
2. Calculate total and average marks.
3. Display all students entered in the current session.
4. Search for a student by roll number.
5. Find the highest scorer based on average marks.
6. Use a simple menu-driven interface.

# Python concept used

The source code demonstrates a list for storing records, dictionaries for individual student information, functions for separate tasks, loops for searching and finding the highest scorer, conditional statements for menu decisions and grade rules, and console input/output.
